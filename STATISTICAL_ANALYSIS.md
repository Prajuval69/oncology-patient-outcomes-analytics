# Statistical Analysis Specification

## Descriptive statistics
Summarize cohort characteristics with appropriate statistics.

## Survival
Use Kaplan–Meier estimates for time-to-event outcomes. Include:
- time variable
- event indicator
- overall curve
- selected subgroup curves
- number-at-risk information where feasible
- median survival where estimable
- confidence intervals

Use log-rank testing only when the grouping question is appropriate.

## Cox model
Build a multivariable Cox model with documented covariates. Check proportional-hazards assumptions where feasible. Clearly distinguish association from causation.

## Logistic model
Predict a binary response outcome using interpretable covariates. Report coefficients/odds ratios with confidence intervals where appropriate.

## Interpretation
All conclusions must be phrased as associations in this synthetic/observational setting. Avoid clinical recommendations.
